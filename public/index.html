Where this data comes from. WorkTime (cloud.worktime.com) doesn't offer a public API on Nexist's current "Basic" plan — only on-screen reports and CSV/HTML/PDF exports. These numbers were pulled from WorkTime's Attendance, Internet and App/doc reports via a signed-in browser session on 27 Oct 2026.

How this page stays current. On every load, this page tries to pull fresh rows from a Google Sheet — so updating the Sheet (pasting in a new WorkTime export) updates nexist.cloud with no re-upload needed. The badge at the top says whether it loaded live or fell back to the snapshot baked into this file on 27 Oct 2026. If it's stuck on the snapshot, check that the Sheet is still shared as "Anyone with the link — Viewer."

Note on "productivity". The Basic plan doesn't include WorkTime's app/site productivity categorisation, so there's no vendor-classified "productive vs. unproductive" score here. Active % (time actively at the keyboard/mouse vs. idle) is used as the closest available proxy — upgrading the WorkTime plan would unlock true productivity scoring if that's wanted later.
